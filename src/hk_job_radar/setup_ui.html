1你想找什么岗位

这些词决定程序去搜什么。搜到的岗位还要过 AI 打分，所以词填得准，报告才有用。

已填 0 / 7 个

上面这几条是预填的示例，不是你填的。请按你实际想投的岗位改掉—— 原样留着只会把别人的岗位抓回来。

四条规则：① 用英文小写；② 只写岗位名称，别写 python、sql 这类技能词—— 几乎每份招聘都提这些词，写进去等于没有筛选；③ 别用两三个字母的缩写 （ai 会命中 email，ml 会命中 html）；④ 越具体的词越往前放。

银行管培生、毕业生培训计划这类岗位，入职时间在毕业后，值得毕业前一年就投。 填在这里，程序会单独按「全职」去搜它们。不需要就留空。

建议先只开 JobsDB，跑顺了再开第二个。LinkedIn 对自动化最敏感， 首次使用要先在命令行跑一次 python run.py login linkedin 用求职小号登录，否则会被拦到登录页。
