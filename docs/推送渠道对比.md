# 推送渠道对比与配置教程（四个通道任选其一）

> 面向完全不懂技术的人。每一步都写清楚：**点哪里 → 输入什么 → 会看到什么**。
> 只要照着配好**一个**通道，就能收到岗位日报。

---

## 一、一分钟选通道

四个通道**完全平等**，没有哪一个是"默认"或"二等"。你只需要选一个：

| 通道 | 好处 | 代价 | 内地网络 | 配置耗时 |
|---|---|---|---|---|
| **企业微信** | 腾讯官方、**免费、无条数上限**、消息进微信 | 要装一个「企业微信」App（免费、无广告） | ✅ 可直连 | 约 6 分钟 |
| **邮件** | **最通用**，不依赖任何第三方平台；能收到排好版的 HTML 岗位卡片 | 第一次可能进垃圾箱，需要手动标记一次 | ✅ 可直连 | 约 5 分钟 |
| **Telegram** | 有 ✅/❌ 按钮，可以直接标记"感兴趣/不感兴趣" | 需要能访问 Telegram | ⚠️ 需自备网络条件 | 约 10 分钟 |
| **WxPusher** | 扫码即用，不用装 App | 第三方服务，有免费额度上限 | ✅ 可直连 | 约 3 分钟 |

**怎么选？**

- **只是想稳定收到消息** → 选 **企业微信**（推荐）或 **邮件**。
- **完全不想装新 App** → 选 **邮件**（用你已有的邮箱）。
- **想点按钮做标记** → 选 **Telegram**。
- **想最快配好** → 选 **WxPusher**。

> 💡 **可以同时开多个通道。** `channels` 里写几个，日报和秒推就同时发到几处，
> 一次推送、多端同时收到。只写一个也完全够用。

## 二、通用部分：先找到要改的那一段

1. 打开项目文件夹，找到 **`config.yaml`**（安装脚本已自动生成）。
2. **右键 → 打开方式 → 记事本**。
3. 按 `Ctrl+F` 搜索 **`notify:`**，你会看到这样一段：

```yaml
notify:
  channels:
    - "wecom"                  # ← 改成你要用的通道

  wecom:
    webhook: ""                # 企业微信：填群机器人的 Webhook 地址

  email:
    smtp_host: "smtp.qq.com"
    smtp_port: 465
    user: ""                   # 你的完整邮箱地址
    auth_code: ""              # ★ 邮箱授权码（不是登录密码）
    to: ""                     # 收件邮箱
    use_ssl: true

  telegram:
    bot_token: ""
    chat_id: ""

  wxpusher:
    app_token: ""
    uids: []
```

4. 把 `channels` 下面的那一行改成你要用的通道名：`wecom` / `email` / `telegram` / `wxpusher`
   （**注意：是英文小写，并且要带引号**）。
5. 然后只填**这一个通道**下面的内容，其余三个整段保持原样不动就行。

> 💡 **改完一定要按 `Ctrl+S` 保存**，否则不生效。改完配置需要**重启**程序（关掉黑窗口再重新双击）。

## 二·五、配完立刻验证（强烈建议，10 秒）

配好任意一个通道后，回到项目文件夹：

- **Windows**：双击 **`notify_test.bat`**
- **Mac**：双击 **`notify_test.command`**
- 或者在有终端的情况下运行：`python run.py notify test`

黑窗口会打印这样几行：

```
正在向 1 个通道发送测试消息：企业微信
  ✅ 企业微信：发送成功，去你的收件端看一眼
```

然后**去手机 / 邮箱看一眼**：

- **收到消息** → 通道配置正确，可以开始用了。
- **没收到** → 看黑窗口里 ❌ 那一行写了什么，再打开 `data\logs\` 当天那个日志文件找原因，
  或者直接对照本文最后一节的《收不到消息？》排查表。

> 这个命令**只发一条"测试消息"，不抓取任何岗位**，几秒钟就结束，可以放心反复点。

## 三、通道 A：企业微信（推荐）

### A-1 装「企业微信」并注册（约 3 分钟）

1. 手机应用商店搜索 **「企业微信」**，安装（图标是绿色底 + 白色对话气泡）。
2. 打开 App，点右下角 **「注册」**（或「创建企业/团队」）。
3. 依次填：
   - **企业名称**：随便填，比如 `我的求职助手`（只有你自己看得到，没人会来查）
   - **你的姓名**：填你自己的名字
   - **行业**：随便选一个
4. 一路点 **「下一步」** 完成，进入 App 首页。

### A-2 建一个「只有自己」的群（约 1 分钟）

5. 点底部 **「消息」** 页 → 点**右上角的 `+`** → 选 **「发起群聊」**。
6. 在选择成员页面里，**找到并勾上你自己的名字** → 点**右上角「确定」**。
   - 如果列表里找不到自己 / 不允许只选自己：**邀请一位家人或朋友加入你的企业**
     （通讯录 → 添加成员 → 发邀请链接给他，他同意后就能建群了），然后再建群。
7. 群建好了，给它起个名字，比如 `岗位推送`。

### A-3 添加群机器人，复制 Webhook（约 2 分钟）

8. 进入刚才那个群 → 点**右上角的 `…`**（群设置）。
9. 在设置列表里找到并点 **「群机器人」**。
10. 点 **「添加机器人」** → 点 **「新创建一个机器人」**。
11. 给它起个名字，比如 `岗位雷达` → 点 **「添加」**。
12. 屏幕上会出现一个 **Webhook 地址**，长得像：

```
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=693a91f6-7xxx-4bc4-97a0-0ec2sifa5aaa
```

13. 点 **「复制」**，把它粘贴到你电脑上 `config.yaml` 的这一行（引号中间）：

```yaml
  wecom:
    webhook: "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你复制到的那串"
```

14. 确认上面 `channels:` 下面写的是 `- "wecom"`，然后 **`Ctrl+S` 保存**。

### A-4（可选）让个人微信也能收到

企业微信的群消息默认只在「企业微信」App 里显示。如果你希望**少装一个 App**：

- 在企业微信里找 **「我 → 设置 → 账号」**，看有没有 **「绑定微信」** 这一项
  （不同版本位置略有差别，也可能叫「微信插件」）。有就绑定。
- ⚠️ 绑定后能不能在微信里看到**群消息**，各版本表现不一致。
  **如果绑了还是收不到，直接看「企业微信」App 就行**——它本身免费、无广告、也不会
  给你推无关内容，装一个不亏。

## 四、通道 B：邮件（最通用）

### B-1 拿到「授权码」（关键在于：这不是你的登录密码）

以 **QQ 邮箱** 为例：

1. 电脑浏览器打开 **mail.qq.com**，登录你的 QQ 邮箱。
2. 点顶部的 **「设置」** → **「账户」**。
3. 往下滚，找到 **「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」**。
4. 找到 **「IMAP/SMTP服务」**，点右边的 **「开启」**。
5. 按提示用**手机发一条短信**（内容是页面给你的那串），发完点 **「我已发送」**。
6. 页面会弹出一串 **16 位授权码**（大小写字母混合）。**复制它。**
   - ⚠️ 这串**只显示一次**，先粘到记事本里存着。
   - ⚠️ 它**不是**你的 QQ 密码，是专门给程序用的口令。别把它发给别人。

> 用 **163 邮箱**：设置 → POP3/SMTP/IMAP → 开启 → 设置「客户端授权密码」，同样是 16 位。
> 用 **Gmail**：需要先在 Google 账号里开启「两步验证」，再生成「应用专用密码」。
> 用 **Outlook**：一般直接用账号密码即可，若失败则去账号安全页生成应用密码。

### B-2 填进配置

7. 在 `config.yaml` 里填这几行（`smtp_host` 按你的邮箱改）：

| 你的邮箱 | `smtp_host` 填 |
|---|---|
| QQ 邮箱 | `smtp.qq.com` |
| 163 邮箱 | `smtp.163.com` |
| Gmail | `smtp.gmail.com` |
| Outlook / Hotmail | `smtp.office365.com` |

```yaml
notify:
  channels:
    - "email"                  # ← 确认这里是 email

  email:
    smtp_host: "smtp.qq.com"   # 按上表改
    smtp_port: 465             # 一般保持 465 不用改
    user: "你的邮箱@qq.com"     # 你的完整邮箱地址
    auth_code: "刚才复制的16位授权码"
    to: "你的邮箱@qq.com"       # 想发到别的邮箱就改这里；多个用英文逗号分隔
    use_ssl: true
```

8. **`Ctrl+S` 保存**。

9. **收到第一封后请去「垃圾邮件」文件夹看一眼**——第一次发送很可能被归到那里。
   找到后点 **「标记为非垃圾邮件」**（或把它加入白名单），以后就会正常进收件箱。

## 五、通道 C：Telegram

1. 手机或电脑安装 **Telegram**（https://telegram.org ，用手机号注册）。
2. 在 Telegram 顶部的**搜索框**输入 `@BotFather`，点开这个官方账号（带蓝色认证勾）。
3. 点下方 **「开始 / Start」**。
4. 它回复一堆按钮，**点 `/newbot`**。
5. 它问「给你的机器人起个名字」——随便起，比如 `我的岗位雷达`，发送。
6. 它又问「用户名」——必须以 `bot` 结尾，比如 `my_job_radar_bot`，发送。
7. 它会给你一串 token，长得像：

```
Use this token to access your HTTP API:
1234567890:AAExampleTokenReplaceMeHere
```

   **这一长串就是 `bot_token`**，复制保存。

8. **先给你的机器人随便发一条消息**（点开和它的对话，发个 `hi`）——这步不能省。
9. 电脑浏览器地址栏输入下面这行（把 `<你的token>` 换成刚复制的），回车：

```
https://api.telegram.org/bot<你的token>/getUpdates
```

   例如：`https://api.telegram.org/bot123456:ABC-xxx/getUpdates`

10. 页面会显示一大段 JSON。按 `Ctrl+F` 搜索 **`"chat"`**，附近有一行
    `"id":1234567891` —— **这个数字就是 `chat_id`**。
    - 如果显示 `{"result":[]}` 是空的：回到第 8 步再给机器人发一条消息，然后刷新页面。

11. 填进 `config.yaml`：

```yaml
notify:
  channels:
    - "telegram"               # ← 确认这里是 telegram

  telegram:
    bot_token: "1234567890:AAExampleTokenReplaceMeHere"
    chat_id: "1234567891"
```

12. **`Ctrl+S` 保存**。

> Telegram 是四个通道里**唯一带 ✅/❌ 按钮**的：收到岗位后可以直接点「感兴趣 / 不感兴趣」，
> 系统会记住你的偏好。其他三个通道只发链接，需要你自己去点开看。

## 六、通道 D：WxPusher（最快）

1. 浏览器打开 **https://wxpusher.zjiecode.com** 。
2. 点 **「登录」** → 用**微信扫码**登录。
3. 进入左侧 **「应用管理」** → 点 **「创建应用」**。
4. 填：
   - **应用名称**：随便，比如 `岗位雷达`
   - **应用描述**：随便
   - 其余能跳过的都跳过
5. 创建完成后，应用详情页会显示一串 **appToken**（以 `AT_` 开头）。**复制它。**
6. 还是在应用详情页，找到 **「关注二维码」** → **用微信扫码关注**你刚创建的应用。
   - 这一步不能省：没关注就收不到消息。
7. 左侧菜单进入 **「用户管理」**，就能看到你刚才关注产生的 **UID**（以 `UID_` 开头）。**复制它。**
8. 填进 `config.yaml`：

```yaml
notify:
  channels:
    - "wxpusher"               # ← 确认这里是 wxpusher

  wxpusher:
    app_token: "AT_你复制的token"
    uids: ["UID_你复制的uid"]
```

9. **`Ctrl+S` 保存**。

> WxPusher 是第三方免费服务，**有免费额度上限**（条数按天算）。
> 日常收一份日报完全够用；如果你担心额度，改用企业微信或邮件更稳。

## 七、收不到消息？按这个顺序查

| 现象 | 先查这个 |
|---|---|
| **不确定哪里配错了** | **先双击 `doctor.bat`（Mac 是 `doctor.command`）** —— 15 项体检，会直接点名是「AI 密钥」还是「推送通道」没过，并告诉你改哪一行。比对着表格逐项猜快得多 |
| 完全没反应 | `config.yaml` 里 `channels:` 下面写的通道名，和你**实际填了凭据的那个**是不是同一个？ |
| 日志提示「配置错误」 | 黑窗口里会打印中文原因（缺哪一项、去哪拿），照着补 |
| 邮件收不到 | 去**垃圾邮件**文件夹找；确认 `auth_code` 填的是**授权码**不是登录密码 |
| 企业微信收不到 | 群里点「群机器人」看看机器人还在不在；Webhook 是不是复制完整了（一串到 `key=` 结尾） |
| Telegram 收不到 | 是不是没给机器人发过 `/start`？或者 `chat_id` 取错了（要用 `"chat"` 附近那个 `id`） |
| WxPusher 收不到 | 是不是忘了**扫码关注**自己创建的应用？ |
| 全都配好了还是没消息 | 双击一次 `report_now.bat`（Mac 是 `report_now.command`）看黑窗口里打印了什么 |

**改完配置一定要重启程序**（关掉黑色窗口，重新双击 `start.bat` / `start.command`）。

## 八、多通道与推送节奏

| 想做的事 | 怎么做 |
|---|---|
| 同时收几个通道 | `channels` 里写几个就发几个，一次推送、多端同时收到 |
| ≥80 分岗位马上知道 | 默认开启，抓到就单独推一条，不必等日报 |
| 一天收多份日报 | 在 `config.yaml` 里填 `report_times`，写几个时间点发几份 |
| 手动补发一份 | `report_now.bat` / `report_now.command`，随时可做 |
