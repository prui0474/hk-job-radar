## 第 0 步：先看这里（2 分钟）

### 你会看到的那些文件，分别是什么？

下载完之后，你会看到一个文件夹，里面有很多文件。**你只需要认识下面这 8 个**，
其它的一概不用管：

| 文件名 | 中文意思 | 什么时候点它 |
|---|---|---|
| `install.command` | 安装 | **只点一次**，第一次装的时候 |
| `start.command` | 开始监控 | 想让它一直挂着自动找岗位时 |
| `run_once.command` | 只跑一轮 | 只想现在跑一次、跑完就关机时 |
| `report_now.command` | 立刻要一份日报 | 不等 9 点，现在就想看报告 |
| `login_jobsdb.command` | 登录 JobsDB | 第一次用、或被网站拦住时 |
| `login_linkedin.command` | 登录 LinkedIn | 想让 LinkedIn 也抓到更多岗位时 |
| `关闭自动运行.command` | 关掉每天自动跑 | 不想让它每天自动运行时 |
| `MAC-打不开就读我.txt` | 打不开时的救命文档 | 双击没反应 / 提示"无法验证开发者"时 |

> ⚠️ **`.command` 和 `.bat` 的区别**
> `.bat` 是给 Windows 用的，在 Mac 上双击没有用。
> `.command` 是给 Mac 用的。你以后在教程里看到别人说"双击 install.bat"，
> 在 Mac 上就换成 `install.command`。

### 为什么 Mac 上的提示是中文，Windows 是英文？

不是双标。Windows 那个黑窗口（命令提示符）有个老毛病：它读中文的批处理
文件时会读错，把中文当成命令去执行，然后报一堆看不懂的错。所以 Windows
那边的脚本只能写英文。

Mac 的终端天生支持中文，没有这个毛病，所以这里直接说中文，看着更舒服。

### 名词对照表（后面会反复出现）

| 名词 | 说人话 |
|---|---|
| **终端 / Terminal** | 一个黑底白字的窗口，靠打字下命令。本教程只有"打不开就读我"那个方法里需要用到它。 |
| **Python** | 运行这个程序的"底座"。你的 Mac 现在**很可能没有**，第 1 步要装。 |
| **虚拟环境（.venv）** | 一个只属于本项目的独立小房间。装在这里的库不会和你电脑上别的东西打架，以后删掉整个文件夹就等于卸载干净。 |
| **pip** | Python 的"应用商店"，用来下载程序需要的各种零件。 |
| **Chromium** | 一个浏览器内核。程序要用它去自动打开招聘网站（约 150MB，只下载一次）。 |
| **API key** | 一串以 `sk-` 开头的密码，证明"是你在用 AI 服务"。 |
| **launchd / 定时任务** | Mac 自带的闹钟。本程序会设一个"每天 09:00 自动跑一次"的闹钟。 |

## 第 1 步：装 Python（5-10 分钟）

**先确认你到底有没有 Python。** 这一步不能跳过——没有它会卡住。

### 怎么确认？

1. 打开「访达」（Finder，底下那排图标里像笑脸的那个）

2. 顶部菜单栏 →「前往」→「实用工具」（快捷键 `Command + Shift + U`）

3. 双击「终端」（Terminal），会弹出一个黑底窗口

4. 在黑窗口里输入下面这一行（可以复制粘贴），然后按回车：

   ```
   python3 --version
   ```

5. 看结果：

| 你看到的 | 说明 | 要做什么 |
|---|---|---|
| `Python 3.12.4`（3.10 或更高） | 已经装好了 ✅ | 跳到第 2 步 |
| `Python 3.9.6` | 是 Mac 自带的版本，**太旧了**，本程序要 3.10+ | 继续往下装 |
| 弹出一个窗口说"需要安装命令行开发者工具" | 也是没有装好 | **先点那个窗口的「取消」**，然后继续往下装 |
| `command not found: python3` | 完全没有 | 继续往下装 |

> 那个"需要安装命令行开发者工具"的弹窗，是苹果让你装 Xcode 开发工具的，
> 装它有 5GB 以上，对本程序完全没必要。**点取消**就好。

### 装 Python

1. 用浏览器（Safari / Chrome 都行）打开这个网址：

   ```
   https://www.python.org/downloads/macos/
   ```

2. 页面最上面有一个**黄色的大按钮**，写着类似
   「Download Python 3.13.x」——
   **点它**。（不要点左边栏那些写着 "Python 3.9" 的老版本）

3. 会下载一个 `.pkg` 结尾的文件（约 50MB）。下载完成后，
   **双击它**。

4. 会出现一个安装窗口，一路点：
   - 「继续」
   - 「继续」
   - 「同意」（会让你读一份许可协议，点「同意」）
   - 「安装」
   - 中途会弹窗要你输入 **Mac 的开机密码**，输入后点「安装软件」

5. 最后点「关闭」。

6. **重要**：关掉终端窗口，重新打开一个新的（重复上面第 1-3 步），
   再输入一次：

   ```
   python3 --version
   ```

   这次应该显示 `Python 3.13.x` 或类似的 3.1x 版本了。

> 💡 如果还是显示 3.9.6：把终端窗口完全关掉（`Command + Q`）再重开一次。
> 终端只在启动时读一次环境，旧窗口读不到新装的 Python。

## 第 2 步：把项目下载到电脑（2 分钟）

1. 用浏览器打开项目的 GitHub 页面。

2. 找到绿色的 **`Code`** 按钮，点它 → 在弹出的小窗里选
   **`Download ZIP`**。

3. 下载完成后，去「下载」文件夹，找到那个 `.zip` 文件，
   **双击解压**（Mac 会自动解压成一个同名文件夹）。

4. **把解压出来的文件夹拖到一个"安全"的位置**，建议放在你的用户主目录下，
   也就是 `/Users/你的名字/` 下面。

   > ⚠️ **千万不要放在「桌面」「文稿」「下载」这三个文件夹里直接运行。**
   > 这三个位置被 macOS 特别保护，程序可能因为权限不足而失败，
   > 报错通常是 `Operation not permitted`。
   > 想放桌面的话，请把它先复制到 `/Users/你的名字/` 下再运行。

5. **顺便改个名**（可选但推荐）：把文件夹名改成 `hk-job-radar`
   （全英文、没有空格）。中文名或空格有时会让某些程序犯迷糊。

## 第 3 步：解除 Apple 的安全拦截（2 分钟）

**这一步不能跳过。** 因为项目是从网上下载的，Apple 会拦住它，
你要手动放行一次。

1. 在文件夹里找到 **`install.command`**

2. **按住键盘上的 `Control` 键不放**，同时用鼠标点一下它

3. 弹出的菜单里选最上面的 **「打开」**

4. 会弹出一个警告窗口，写着"无法验证开发者"——
   **点窗口里的「打开」按钮**（不是「完成」，不是「移到废纸篓」）

5. 如果成功，你会看到一个黑窗口弹出来开始刷字 —— 那就对了，
   直接跳到第 4 步。

> **如果第 4 步找不到「打开」按钮，或者双击完全没反应**：
> 打开项目文件夹里的 **`MAC-打不开就读我.txt`**，里面有另外两个办法
> （包括一个"必杀技"，一次放行全部文件）。

## 第 4 步：双击 `install.command`（5-10 分钟）

双击 `install.command` 之后，会弹出一个黑窗口。**这个窗口不要关**，
让它自己跑。你会依次看到：

| 屏幕上显示 | 意思 |
|---|---|
| `[1/5] ...` 找到 Python | 检查通过 |
| `[2/5] 正在创建虚拟环境` | 约 10 秒 |
| `[3/5] 正在安装依赖` | 1-3 分钟，**最慢的一步** |
| `[4/5] 正在下载浏览器内核 Chromium` | 1-3 分钟，约 150MB |
| `[5/5] 已生成 config.yaml` | 快好了 |
| 「把 key 粘贴到这里，然后按回车」 | 需要你操作一下 ↓ |
| 「安装完成！还剩 4 件小事」 | ✅ 成功了 |

### 中途它会问你 DeepSeek 的 key

如果这时候你**还没有** key，**直接按回车跳过**就行（以后可以随时补）。
如果已经有了，就粘贴进去再按回车。

### 跑完之后它会自动做一件好事

它会顺手帮你设置**「每天 09:00 自动抓一轮」**。
这就相当于给 Mac 设了个闹钟，以后每天到点自己跑一遍，
即使当时电脑在睡觉，醒来后也会补跑一次。

不想让它自动跑？**双击 `关闭自动运行.command`** 就能取消，
随时可以重跑 `install.command` 再打开。

### 如果看到 `[X]` 开头的红字

说明那一步失败了。**把整个黑窗口截图发给我**，别自己猜。
最常见的失败原因是网络问题，重新双击 `install.command` 再试一次通常就好了。

## 第 5 步：申请一个 DeepSeek key（5 分钟）

（如果你在第 4 步已经填过，可以直接跳到第 6 步。）

1. 浏览器打开：`https://platform.deepseek.com`

2. 点右上角「注册」，用手机号或邮箱注册并登录

3. 登录后，看**左边那一列菜单**，找到 **「API Keys」**，点它

   > 名字可能叫「API 密钥」，图标一般是一把钥匙。

4. 点 **「创建 API key」**（可能叫「创建新的 API key」）

5. 起个名字（随便写，比如 `job-radar`），点确认

6. 屏幕上会出现一串以 `sk-` 开头的长文字。
   **立刻复制它** —— 这串文字只会显示这一次，关掉就再也看不到了。

7. 把它存到项目里：
   - 回到项目文件夹
   - 用「文本编辑」（TextEdit）新建一个文件
   - **只写那串 key**，前后不要有空格、不要有换行后的多余内容
   - 保存为 **`api_key.txt`**，放在项目文件夹根目录（和 `install.command` 同一层）
   - ⚠️ 保存时如果 TextEdit 问你要不要加 `.txt` 后缀，选**「使用 .txt」**，
     别搞成 `api_key.txt.rtf` 或 `api_key.txt.txt`

> 💰 钱的事：DeepSeek 是**按用量付费**，而且非常便宜。
> 给一个岗位打分大约消耗 1000 个字，一万个岗位也就几块钱。
> 平台会送一点免费额度，够你试很久。

## 第 6 步：填写 `config.yaml`（5 分钟）

这个文件是"告诉程序：我要找什么样的工作、消息发到哪里"。

### 怎么打开它

在项目文件夹里找到 `config.yaml` → **右键** → **「打开方式」** → 选
**「文本编辑」**（TextEdit）。

> ⚠️ **不要用 Microsoft Word 打开**。Word 会把它存成另一种格式，程序就读不懂了。
> 如果 TextEdit 打开后显示成一堆格式混乱的东西：
> 菜单栏 →「格式」→「制作纯文本」，再重新打开。

### 要改两处

**第一处：Telegram 推送设置**

找到开头是 `telegram:` 的那两行：

```yaml
telegram:
  bot_token: ""       ← 把引号里填上你的 token
  chat_id: ""         ← 把引号里填上你的 chat_id
```

这两个值怎么拿：

1. 手机上装 Telegram（香港用户可以直接用；**内地网络需要科学上网**）
2. 在 Telegram 里搜索 **`@BotFather`**，点进去，按「开始」
3. 发一句 `/newbot`，它会问你两个问题：
   - 机器人叫什么名字（随便起，比如 `我的求职雷达`）
   - 机器人的用户名（必须以 `bot` 结尾，比如 `my_job_radar_bot`）
4. 它回复的一大段文字里，有一行 `Use this token to access the HTTP API:`
   后面那串形如 `123456789:ABCdef...` 的，就是 **bot_token**
5. 再搜索 **`@userinfobot`**，点「开始」——它给你的 `Id:` 后面那串数字就是 **chat_id**
6. 回到 `config.yaml`，把这两个值填进引号里，保存

> ⚠️ **内地用户注意**：Telegram 在内地无法直接访问。
> 我们会在后续版本里加入**微信推送**和**邮件推送**，不需要科学上网。
> 如果你现在就被这一步卡住，先跳过，告诉我一声。

**第二处：求职关键词（必须改）**

找到 `keywords:` 那一段。模板里它是**空的**（`keywords: []`），
刻意不预置任何示例——必须换成你自己想找的岗位名称。

```yaml
keywords:
  - data analyst          ← 按你自己想找的方向写，示例仅作格式参考
  - business analyst
```

现在模板里是 `keywords: []`，把它整行替换成上面的形式即可。

写得越具体越准。比如你是学金融的，可以写：
`financial analyst`、`risk analyst`、`investment analyst`。

### 保存

`Command + S` 保存，然后关掉窗口。

## 第 7 步：填写你的个人画像（8 分钟）

**这一步千万别跳过。** AI 就是拿这份画像去判断"这个岗位适不适合你"的，
画像空着，打出来的分就没有意义。

### 打开它

项目文件夹里 → `data` 文件夹 → `profiles` 文件夹 → `profile.yaml`
（右键 →「打开方式」→「文本编辑」）

### 最省力的填法

1. 打开 DeepSeek 的网页对话：`https://chat.deepseek.com`
2. 把你的简历内容**整段粘贴**进去
3. 再把 `profile.yaml` 的**全部内容**也粘贴进去
4. 然后说一句：

   > 请根据我上面的简历，帮我把这份 YAML 模板填好，保持原有的结构和注释，
   > 只把我的真实信息填进去。不要编造我没有的经历。

5. 把它给你的结果**整段复制**，覆盖掉 `profile.yaml` 里的全部内容，保存

> 模板文件里每条字段后面都写了中文说明，告诉你这一栏该填什么，
> 想看明白再填也可以。

## 第 8 步：登录一次 JobsDB（1 分钟）

1. 双击 **`login_jobsdb.command`**

2. 会弹出一个浏览器窗口，打开 JobsDB

3. **如果页面上出现"正在验证您是否是真人"（一个勾选框），手动点一下那个框**

4. 验证通过、能看到正常页面后，回到那个黑窗口，**按回车**

5. 窗口显示结束信息，关掉即可

> 这一步是让程序记住"这次是你本人访问的"，之后就很少再被拦。
> 以后如果又被拦住，再双击一次就行。

## 第 9 步：先自检，再跑第一次（3-8 分钟）

### 9a. 双击 `doctor.command` 体检一次（强烈建议）

它会把 14 个环节全查一遍：Python、依赖、浏览器内核、配置、关键词、个人画像、
AI 密钥、AI 连通、推送通道、数据目录、数据库……

- 带 **✅** 的没问题
- 带 **❌** 的必须改，`→` 后面就写着该改哪一行
- 一行行对照改完，再双击一次，直到全绿

> 用它比自己在 Terminal 里猜要快十倍 —— 尤其是「填了但填错位置」这类问题。

### 9b. 双击 `run_once.command` 跑第一次

1. 双击 **`run_once.command`**

2. 会依次弹出浏览器窗口（JobsDB，如果你开了 LinkedIn 还会有 LinkedIn），
   自动翻页找工作。**不要手动去操作那些浏览器窗口。**

3. 每翻一页它会随机等 2-8 秒 —— 这是故意的，模仿真人节奏，防止被封号。

4. 跑完后黑窗口会显示类似这样的一行行结果：

   ```
   jobsdb     抓到  63 → 初筛留  13 → 新入库  12 → 已打分  12（打分失败 0）
   实时推送（≥80 分）   4 个
   日报：已推送 ✅
   ```

5. 同时你的 **Telegram 里会收到一条消息**，就是今天的岗位日报。

**跑到这里就算成功地跑通了 🎉**

## 日常使用

装好之后，平时你只需要记住这几个文件：

| 你的情况 | 双击哪个 |
|---|---|
| 电脑基本一直开着 | `start.command`（保持窗口开着；关掉窗口=停止监控） |
| 每天只开一小会儿电脑 | `run_once.command`（跑一轮、看结果、关机） |
| 每天 09:00 自动跑（安装时已设好） | **什么都不用点** |
| 现在就想看今天的报告 | `report_now.command` |
| 感觉哪里不对 / 想确认配置对了 | `doctor.command`（14 项体检，直接点名问题） |
| 想看今天抓了多少 | 在终端里运行 `run_once.command` 之后它会自己打印汇总 |

## 常见问题

**Q：双击 `.command` 文件完全没反应 / 提示"无法验证开发者"？**
打开 `MAC-打不开就读我.txt`，里面有详细步骤。

**Q：黑窗口里出现一大堆英文报错，看不懂？**
不用看。**把整个窗口截图**发给我，并告诉我"我做到第几步"，
我基本一句话就能告诉你怎么解决。

**Q：提示 `Operation not permitted`？**
项目文件夹在「桌面」「文稿」「下载」这类受保护的位置。
把整个项目文件夹挪到 `/Users/你的名字/` 下面再跑。

**Q：跑到一半卡住不动了？**
先等 5 分钟。有些招聘网站响应很慢。如果超过 10 分钟没有任何新文字，
截图发我。

**Q：收到的岗位分数都很怪 / 推送的岗位完全不相关？**
八成是第 7 步的「个人画像」没填，或者第 6 步的关键词还是模板里的示例。
回头检查这两个文件。

**Q：Telegram 收不到消息？**
- 确认 `bot_token` 和 `chat_id` 都填了、没有多余空格
- 确认你**已经给那个机器人发过一条消息**（发 `/start` 就行）——
  没发过的话机器人不能主动找你
- 内地网络无法访问 Telegram，这是已知限制

**Q：想换成找别的方向的岗位？**
改 `config.yaml` 里的 `keywords`，保存，下次跑就生效。

**Q：想彻底卸载？**
把整个项目文件夹拖进废纸篓，然后双击一次 `关闭自动运行.command`（在删之前做）
取消定时任务。虚拟环境都在项目文件夹里，删掉就干净了。

**Q：`.bat` 结尾的文件我要点吗？**
不要。那些是给 Windows 用的，在 Mac 上双击不会正常工作。
Mac 上看 `.command` 结尾的。
