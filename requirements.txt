# 【注意】上面第 1 行的编码声明不要删，也不要挪位置！
#
# 原因：简体中文 Windows 的 cmd 里，Python 的「首选编码」是 GBK(cp936)。
# pip 在读取本文件时，如果既看不到 BOM、也看不到编码声明，就会用 cp936 去
# 解码整个文件；而本文件带中文注释，于是 pip 直接崩溃并抛出：
#
#     UnicodeDecodeError: 'gbk' codec can't decode byte 0xad in position 85
#     decoding with 'cp936' codec failed
#
# 第 1 行的 PEP 263 声明（# -*- coding: utf-8 -*-）会明确告诉 pip「按 UTF-8
# 读」，问题即消失。它只在 1、2 行内生效，所以务必留在最上面。
# 即使你把下面所有中文注释都删掉，保留这一行也完全无害。
